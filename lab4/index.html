01 / ЖҰМЫСТЫҢ БАҒЫТЫ

Бүгін не
үйренесіз?

Жұмыстың мақсаты — Git жүйесінде тармақтармен жұмыс істеуді меңгеру: жаңа тармақ құру, олардың арасында ауысу, тармақтарды біріктіру және біріктіру кезіндегі қақтығыстарды шешу.

GitBranchMergeConflict
⌘
Қажетті бағдарламалар

Компьютерде Git орнатылған болуы керек. Командаларды орындау үшін терминал және файлдарды өңдеу үшін Visual Studio Code немесе басқа мәтіндік редактор қажет.

02 / ТӘЖІРИБЕЛІК БӨЛІМ

Жұмысты кезең-кезеңімен
орындаңыз.

Әр кезеңді ретімен орындап, командаларды терминалға енгізіңіз. Дайын болған қадамдарды белгілеп отырыңыз.

Орындалу барысы0 / 6 бөлім
01
БІРІНШІ КЕЗЕҢ

Репозиторийді дайындау

Жаңа Git репозиторийін жасап, бастапқы README.md файлын сақтаңыз.

TERMINAL
git init my-branching-repo
cd my-branching-repo
echo "# Менің Git жобам" > README.md
git add README.md
git commit -m "Initial commit"
i

Ескерту: Егер Git пайдаланушы аты мен электрондық поштаны сұраса, алдымен git config --global user.name және git config --global user.email параметрлерін орнатыңыз.

02
ЕКІНШІ КЕЗЕҢ

Тармақтар құру және жұмыс істеу

feature-a және feature-b атты екі тармақ құрып, әрқайсысына жеке файл қосыңыз.

FEATURE-A ТАРМАҒЫ
git switch -c feature-a
echo "Бұл — A мүмкіндігі" > feature-a.txt
git add feature-a.txt
git commit -m "Added feature-a.txt"
FEATURE-B ТАРМАҒЫ
git switch main
git switch -c feature-b
echo "Бұл — B мүмкіндігі" > feature-b.txt
git add feature-b.txt
git commit -m "Added feature-b.txt"
!

Егер бастапқы тармақтың атауы master болса, командалардағы main сөзінің орнына master деп жазыңыз.

03
ҮШІНШІ КЕЗЕҢ

Тармақтарды біріктіру

Негізгі тармаққа қайта ауысып, екі тармақтың өзгерістерін біріктіріңіз. Содан кейін коммиттер тарихын қараңыз.

TERMINAL
git switch main
git merge feature-a
git log --oneline --graph
git merge feature-b
i

Біріктіру кезінде Git өзгерістерді негізгі тармаққа қосады. git log --oneline --graph командасы коммиттер тарихын график түрінде көрсетеді.

04
ТӨРТІНШІ КЕЗЕҢ

Қақтығысты әдейі туындату

Бір файлға екі тармақтан бөлек өзгеріс енгізіп, оларды біріктіргенде туындайтын қақтығысты бақылаңыз.

FEATURE-A ТАРМАҒЫНДА
git switch feature-a
echo "A тармағындағы өзгеріс" >> feature-a.txt
git add feature-a.txt
git commit -m "Updated feature-a.txt"
MAIN ТАРМАҒЫНДА
git switch main
echo "Негізгі тармақтағы өзгеріс" >> feature-a.txt
git add feature-a.txt
git commit -m "Updated feature-a.txt in main"
git merge feature-a
!

Git қақтығыс туралы хабарласа, бұл — осы кезеңде күтілетін жағдай. Қақтығыс бір файлдың бір бөлігіне екі тармақтан сәйкес келмейтін өзгерістер енгізілгенде пайда болады.

05
БЕСІНШІ КЕЗЕҢ

Қақтығысты шешу және тармақтарды жою

Қақтығыс болған файлды ашып, қажет өзгерістерді қалдырыңыз. Арнайы белгілерді алып тастап, біріктіруді аяқтаңыз.

ҚАҚТЫҒЫСТЫ ШЕШУ
# feature-a.txt файлын редакторда түзетіңіз
git add feature-a.txt
git commit -m "Resolved conflict in feature-a.txt"

Файл ішіндегі <<<<<<<, ======= және >>>>>>> белгілерін жойып, сақталуы тиіс мәтінді қалдырыңыз.

ТАРМАҚТАРДЫ ЖОЮ
git branch -d feature-a
git branch -d feature-b
i

Тармақты жою үшін ол басқа тармаққа біріктірілген болуы керек. Егер Git жоюға рұқсат бермесе, алдымен тармақтың біріктірілгенін тексеріңіз.

06
АЛТЫНШЫ КЕЗЕҢ

Соңғы тексеру

Репозиторийдің күйін және коммиттер тарихын тексеріңіз. Өзгерістердің дұрыс сақталғанына көз жеткізіңіз.

TERMINAL
git status
git log --oneline --graph
✓
Жұмыс аяқталды!

Репозиторийдің күйі таза, барлық қажетті өзгерістер сақталған болуы керек.

03 / ҚОРЫТЫНДЫ

Есепті
дайындаңыз.

Зертханалық жұмысты аяқтаған соң, орындалған әрекеттерді қысқаша сипаттап, дәлел ретінде скриншоттарды тіркеңіз.

01

Орындалған Git командалары мен әрекеттердің сипаттамасы.

02

Тармақ құру, біріктіру және қақтығысты шешу кезеңдерінің скриншоттары.

03

Жұмыс барысында кездескен мәселелер және оларды шешу жолдары.
