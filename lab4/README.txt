ЗЕРТХАНАЛЫҚ ЖҰМЫС №4 — GIT ТАРМАҚТАРЫ

Іске қосу:
1. ZIP архивін ашыңыз.
2. index.html файлын браузер арқылы ашыңыз.

Файлдар:
- index.html — сайт құрылымы
- style.css — дизайн және бейімделгіш стильдер
- script.js — интерактивті мүмкіндіктер (тапсырмаларды белгілеу, командаларды көшіру)

Сайт қазақ тілінде жасалған. Интернет қосылымы болғанда Google Fonts қаріптері жүктеледі.
